# 《如果当时》· 策划案（网页版 v0.7）

> 现代人生抉择游戏。副题：**人生的岔路，你敢重走几次？**

## 一、一句话定位

把"500 万 vs 清华"这类电车难题做成一局可玩的人生：**玩家不是"选对"，而是看清每个选择背后放弃了什么。**

## 二、核心玩法：多岔路串行 + 四维数值 + 连锁 + 事件

```
开始新人生（随机种子）
  → 抽一道热议选择题（二选一 / 多选限选）定人生起点
  → 走完它的连锁剧情（2 拍小抉择）
  → 岔路之间可能插入随机事件（命运变数）
  → 某些选择触发"连锁专属局"（跨关卡回响）
  → 四维数值反过来影响剧情走向与结局
  → 走满 6 道题（约 10 分钟）→ 结算人生报告 + 放弃清单
```

## 三、四维数值系统

`money（钱）/ health（健康）/ social（人脉）/ happy（幸福）`，初始各 50，选项/事件的 `effects` 扣加（0~100）。

- **数值反过来影响走向**：`condition:{stat,op,value}` 门槛决定事件/连锁局是否触发（如 `health<60` 才触发"大病"）。
- **数值影响结局称号**：过低触发特殊结局（贫困/熬垮/不快乐），过高触发"完美人生/世俗赢家"。
- 无显式 effects 的选项按题目标题关键词兜底（`resolveEffects`），保证每道题都有数值反馈。

## 四、连锁触发 + 随机事件

- **连锁专属局**（`PACK_CHAINS`）：选项带 `trigger:{unlock:"debt"}`，后续触发对应专属局（债务危机/梦想召唤/亲情的债/身体的账单）。
- **随机事件**（`PACK_EVENTS`）：岔路之间按 30% 概率插入，事件可带 condition（数值门槛），如"大病""被裁""中彩票""同学聚会"。

## 五、两种题型

### ① 二选一（type 缺省）

选项 A=「得到」（红）、B=「失去」（绿）。选完记 1 条 regret，进入 2 拍连锁剧情。

### ② 多选限选（type: "multi"）

"荒漠求生 10 选 4"等。勾选 N 项，被划掉项逐条记入放弃清单。`tag` 推算 dream/love（测底型开局人设），`effects` 影响四维。

## 六、引擎分层（可复用于小游戏）

| 文件 | 职责 |
|---|---|
| `data/pack-start.js` | 开局题题库（50 题：29 二选一 + 21 多选限选） |
| `data/pack-events.js` | 随机事件池（13 个）+ 连锁专属局（6 个） |
| `js/engine.js` | 状态机 + 洗牌 + 数值 + 连锁 + 事件 + 结算（`RUGO`，纯逻辑） |
| `js/ui.js` | DOM 渲染 + 点击 |

## 七、视觉

深紫黑 `#050010` + 顶部紫光晕 + 磨砂玻璃卡 + 金色 `#E8C268` + 朱红 `#E07866` + 青绿 `#7DD9A6` + 蓝 `#7FB5E0`（人脉）。四维数值条 2×2 网格，连锁局卡片金色高亮"命运的回响"。

## 八、当前状态（v0.7）

- 题库：**75 道开局题**（44 二选一 + 31 多选限选）+ **20 随机事件** + **9 连锁局**。
- v0.7 增量：新增 25 道题、7 个事件、3 个连锁局，全部写在 `data/pack-more.js`（追加，不覆盖原文件）。
- 新增连锁钥匙：`roots`（祖宅与来处）/ `child`（孩子的账）/ `silence`（没说出口的那句话）。
- 引擎：四维数值 + 连锁触发 + 随机事件 + 反向人生 + 人生码 + **结局收藏图鉴**全跑通，5000 局冒烟 0 错误、0 数值越界。
- 结局称号 8 种（含数值触发的特殊结局）。
- 可玩：file:// 直接打开 `index.html` 即玩。

## 九、反向人生（v0.4 新增）

结算后一键「看看当年反着选，会怎样」——引擎记录本局每一步选择路径（`s.path`），`settleReverse` 把每一步反着重放（二选一 A↔B、多选选"原局未选项"、事件反选），算出一个平行结局，并排对比「你的人生」vs「另一种人生」（含各自四维数值 + 各自的放弃清单）。

## 十、人生码（v0.5 新增）

用种子生成可分享的短码，朋友输入可复现同一局开局。

- **编码**：`encodeCode(seed)` → base32 短码（字符集 `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`，无 0/O/1/I 易混字符），6~7 位。
- **解码**：`decodeCode(code)` → 还原 seed，容错跳过非法字符。
- **交互**：首页「输入人生码」弹层 → 输入后 `startGameWithSeed(seed)` 复现开局；结算屏「分享这局人生」弹层 → 展示码 + 一键复制。
- 同一码复现同一局开局（seed 全程保留），但玩家选择不同，后续走向仍是自己的。

## 十一、结局收藏图鉴（v0.6 新增）

用 localStorage（key `rugo-collection-v1`）记录玩家解锁过的结局称号，做成收集系统。

- **引擎**：导出 `ALL_TITLES`（8 种结局称号，即图鉴顺序）。
- **UI**：首页「人生收藏」入口（带 `已解锁 N / 8` 计数）→ `renderCollection` 图鉴屏（进度条 + 已解锁/未解锁卡片网格）；结算屏解锁新称号时显示「✦ 新结局已收入人生收藏」横幅。
- **持久化**：`loadCollection()/unlockTitle(title)`，localStorage 存 JSON 数组。

## 十三、结局称号扩容与分享长图（v0.8 新增）

### 13.1 为什么要改阈值

v0.6 的 8 个称号是按"理想数值"拍的，实跑 3000 局才发现两处失真：

- `health ≤ 8` 的「被生活熬垮的人」**一次也没出现**（健康 p5 = 38）；
- `money ≥ 75 && social ≥ 65` 的「赢家」只占 0.9%，而 34.7% 的局挤在「平凡而滚烫」、27.3% 挤在「追梦人」。

结果是图鉴只有 8 格还能有一格永远收不到，收集系统名存实亡。

### 13.2 新口径：按实跑分位数定阈值

以 3000 局的实际分布（money p50=39 / health p50=53 / social p50=48 / happy p50=48 / 遗憾 p50=17）重定，扩到 **20 个称号**，判定顺序＝稀有在前、兜底在后：

- 一、被某一项压垮（健康/人脉/钱）
- 二、代价换来的东西（燃尽、什么都有什么都缺、谁也没辜负除了自己、谁都不欠谁也不亲）
- 三、都拿到了（赢家、诗、被爱的人、没白活）
- 四、过程（重新开始、追梦、守灯、半途而废、把遗憾收进抽屉、从不肯将就）
- 五、兜底（不快乐、稳稳当当、平凡而滚烫）

实跑分布：最高 15.3%（追梦人），最低 1.1%（不快乐），**20 个全部可达**。每个称号配一句专属判词（`TITLE_COMMENTARY`），不再用一套通用话套二十个结局。

### 13.3 收藏图鉴改版

- 未解锁项不再直接亮出名字，改为「？」＋一句线索（`TITLE_HINTS`），既有目标感又不剧透。
- 加筛选页签：全部 / 已得 / 未得（带计数），进度条加百分数。
- 已得卡与未得卡改用金色实线 / 虚线区分，不再整卡降透明度（0.5 会让线索文字读不清）。

### 13.4 分享长图

「分享这局人生」原来只给一串人生码，朋友拿到还得自己再走一遍。现在直接用 canvas 画一张 **1080×1440** 的结局长图：结局名、专属判词、四维条、放弃几样、人生码、"#如果当时"。

- 全部用 canvas 画，不引用任何外部图片与字体文件，`file://` 双击也能 `toDataURL` 并存图。
- 弹层里预览 + 「存图」下载 PNG；窄屏下三个按钮改两行，避免「复制人生码」被挤成两行字。

### 13.5 验证

- `smoke.js` 1000 局：0 错误、0 越界，20 个称号全部出现。
- 无头截图核对：收藏页（全部/未得）、分享弹层、长图原尺寸四张，均无溢出与遮挡。

## 十四、题库扩容到 95 道（v0.9 新增）

### 14.1 为什么扩

75 道对一局 6 道来说，重复率是 8%——连玩十几局就会开始背答案，而「后悔」这种东西一旦能预判，就不成立了。扩到 95 道后，同一道题的复现间隔拉长到约 16 局。

新增 20 道，全部避开前 75 道已有的角度（钱/教育/工作/婚育/城市/生存假设/伦理/健康）。新开的三片区域是：

- **手足与身世**：父母要你把房子过户给弟弟、发现自己不是亲生的；
- **告别**：老友病危的最后一面、父亲的遗物只能留三样、葬礼上希望别人记住哪三件事；
- **旧债与体检的恐惧**：老友借的钱催不催、体检报告有个结节查不查、医院的复查短信。

### 14.2 结构

| 文件 | 内容 |
|---|---|
| `pack-more2.js` | 10 道二选一（q76–q85），各带两段 follow |
| `pack-more3.js` | 10 道多选限选（q86–q95），各带两段 follow |
| `pack-more4.js` | 6 个随机事件（`ev2.*`）+ 3 个连锁局 |

三道新连锁局的钥匙分别来自新题：`brother`（房本）、`origin`（身世）、`funeral`（没去的那场）。连锁总数 9 → 12。

### 14.3 数值平衡

初稿写得太狠：20 道题的金钱净额为 **-137**（旧题库是 +179，平均每题 +2.4），实跑后「在贫困里打转」从 15.4% 涨到 21.1%。

做了两轮回调，共 20 处：把「付出型选择」改成和对立选项一正一负，而不是两边都亏。例如养老院那条，原本「送」-9、「自己扛」-10，改成送 -6、自己扛 -1（自己扛不花钱，耗的是健康和收入）。

调整后仍占 20%，接受这个数——「为了家人花光积蓄」本来就是这游戏要表达的代价之一，它排在 20 个结局的第一位不算失衡。

### 14.4 验证

- `smoke.js` 1000 局：0 错误、0 越界，20 个称号全部出现。
- 结构自检：95 道无重复 id，多选题 `items` 数量均 ≥ `pickCount`。
- 无新题基线对照：75 道时「在贫困里打转」15.4%，95 道时 20.0%。

## 十五、题库扩容到 126 道（v1.0 新增）

### 15.1 为什么是这八类

95 道时做了一次题材盘点，问题不在总数，在偏科：**家庭与生育占了半壁**（家庭亲情 55 道、生育 43 道），而这类游戏最容易传播的三块反而最薄——婚恋 9 道、朋友人情 9 道、学业 12 道。另有四片完全空白：照护、宠物、返乡、意义。

一局只走 6 道，126 道意味着同一道题的复现间隔约 21 局，比 95 道时的 16 局又拉开一截。重复率是这类游戏真正的寿命上限。

### 15.2 结构

| 文件 | 内容 |
|---|---|
| `pack-more5.js` | q96–q103 婚恋：彩礼、婚前公证、异地、前任、婚后 AA、离婚的房子、二婚带孩子、催婚的春节 |
| `pack-more6.js` | q104–q109 朋友人情：随礼、合伙翻脸、担保、伴郎、老友投奔、朋友抑郁 |
| `pack-more7.js` | q110–q118 学业（志愿 / 考研二战 / 留学回国 / 一作 / 普高职校）+ 照护（护工 / 阿尔茨海默 / 不抢救 / 失能） |
| `pack-more8.js` | q119–q126 宠物（治病 / 安乐）+ 返乡（包地 / 直播）+ 意义（捐一半 / 支教）+ 中年（年龄 / 竞业） |
| `pack-more9.js` | 4 个随机事件 `ev3.*` + 2 个连锁局 |

二选一 83 道、多选限选 43 道（新增两道多选：q103 年夜饭只能回一句话、q118 失能后只能保住三样）。

两道新连锁：`divorce`（钥匙在 q101，二十年后孩子的婚礼上你们坐同一桌）、`care`（钥匙在 q115–q117，轮到你了）。连锁总数 12 → 14。

### 15.3 选题的三条自我约束

1. **不写"选谁"，写"选完以后"。** 前 95 道已经有「相亲还是等真爱」「嫁喜欢的还是合适的」，再写一遍就是同题重开。新题一律从结果切入：彩礼谈崩了怎么收场、离婚时那套房归谁、伴郎那个位置站的是谁。
2. **一题只钉一个具体的物。** 催婚那道钉的是「那碗没喝完的汤」，宠物那道钉的是「越来越安静的航空箱」，照护那道钉的是「简历上那两年空白」。写「心里难受」没人记得住，写「勺子碰在杯子上的声音」才留得下。
3. **金钱净额必须过账。** 95 道时 20 道题的净额是 -106，把「在贫困里打转」从 15.4% 顶到 20.0%。这一批 31 道合计 -17（每选项均值 -0.23），比上一批温和四倍。

### 15.4 新增工具 `tools/balance.js`

原来只有 `smoke.js`（跑不跑得通）和 `reach.js`（抽不抽得到），缺一个**看数**的。新脚本回答三件事：

- 分批次统计题库金钱净额（初版 +179 / v0.9 -106 / v1.0 -17 / 全库 +56）；
- 四维的实际分位数，用来校准称号阈值（不是拍脑袋定「健康 ≤ 8」）；
- 称号分布条，一眼看出谁挤在 30% 以上、谁一局都收不到。

**注意：策略要随机。** 第一版写成「岔路全选 A」，结果 20 个称号只覆盖 13 个、7 个永远收不到——不是内容的问题，是固定策略把分布压平了。改成按种子随机后就全了。

### 15.5 验证

```
牌库 170 张（岔路 126 / 事件 30 / 连锁 14）· 3000 局·一次没出现 0 张
smoke 1500 局：0 报错、0 越界
balance 4000 局：20 / 20 个称号可达，最挤「在贫困里打转的人」15.6%
```

四维分位（随机策略 4000 局）：money p50 35、health p50 55、social p50 50、happy p50 53。放弃清单中位 18 条、最多 32 条。

对比 v0.9：最挤的称号从 20.0% 降到 15.6%，分布比之前更散——补内容顺带把贫困率压了下来。
