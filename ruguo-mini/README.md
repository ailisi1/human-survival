# 如果当时 · 微信小程序

## 一、想法

网页版《如果当时》要复制一个网址打开，分享出去常常断在「复制到浏览器」这一步。
小程序的分享卡片能直接点开，还能带上「人生码」——朋友点一下就走进你这一局的同一起点。

所以这一版不是把网页塞进 web-view，而是把**引擎原样搬过来，视图重写成原生 WXML**：
一局六道岔路、十分钟、二十种结局，和网页版同一套题、同一套判定、同一个种子。

不做的事：不登录、不要手机号、不收集数据、没有排行榜。结局收藏只存在本机。

## 二、做什么

| 页面 | 路径 | 职责 |
|---|---|---|
| 首页 | `pages/index/` | 标题、开始新人生、输入人生码、人生收藏入口 |
| 岔路 | `pages/play/` | **一局全在这里**：二选一 / 多选限选 / 连锁剧情 / 随机事件，四种形态共用一个页面 |
| 结算 | `pages/end/` | 岁数、结局称号、判词、四维评价、放弃清单、人生码 |
| 收藏 | `pages/collect/` | 20 种活法图鉴，分「全部 / 已得 / 未得」 |

关键交互：

- **人生码**：每局一个种子，`RUGO.encodeCode(seed)` 成 6 位短码（字符集避开了 0/O/1/I）。
  结算页点一下复制；分享卡片也带着它，朋友点开直接用同一种子重开。
- **四类卡统一推进**：`play.js` 的 `paint()` 是唯一入口，每次交互后重算「现在该显示什么」，
  不自己记拍数，交给引擎。
- **多选**在本地勾选，勾满才允许确认；未勾的由引擎自动记入放弃清单。

## 三、文件夹说明

```
ruguo-mini/
├── app.js / app.json / app.wxss   入口、全局配置、全局样式（深紫黑牌桌 + 金）
├── project.config.json            开发者工具工程配置（appid 为 touristappid）
├── core/
│   ├── pack.js                    ★ 自动生成：146 道题 + 30 个事件 + 14 组连锁
│   └── engine.js                  ★ 自动生成：网页版引擎，只换了 IIFE 入参
├── pages/                         四个页面，每页 .js/.wxml/.wxss/.json
├── utils/store.js                 结局收藏与上次人生码（wx.storage）
└── tools/verify.js                回归脚本：node 里跑 400 局
```

**`core/` 两个文件不要手改。** 它们由 `如果当时/tools/build-mini.js` 生成：

```bash
node 如果当时/tools/build-mini.js   # 内容更新后重跑
node ruguo-mini/tools/verify.js     # 再验一遍
```

生成方式：数据文件本来就是 `window.PACK_*` 的普通赋值，前面加一句 `var window = {};`
拼成静态源码即可，**不用 eval / new Function**（小程序对动态执行不友好）。引擎只把结尾的
`})(window);` 换成 `})(__data);`。

顺序很重要：必须按 `如果当时/index.html` 里的 `<script>` 顺序拼，因为 `pack-more*.js` 全是
`(window.PACK_X || []).concat([...])`，顺序错了会静默少内容。

## 四、怎么上线

1. **预览**：应用卡点开即看。改完代码后重新发布一次即可刷新预览。
2. **发布**：预览面板右上角 **「分享 / Share」** → 可选试用小程序或绑定已有小程序 →
   上传 → 提交审核 → 正式发布。全程在 WorkBuddy 内完成，**不需要**去微信开发者工具手工上传。
3. 绑定正式小程序需要该小程序的 AppID（企业主体还需确认类目：游戏/工具类均可）。
   试用模式不需要 AppID。

## 五、已知限制

- 分包与体积：`pack.js` 约 389 KB，主包 2 MB 限额内，暂时不需要分包。
- 「反向人生」（看看当年反着选会怎样）网页版有，小程序第一版没做——它要保留整局路径重放，
  和现在的 `redirectTo` 结算流程冲突，留作下一版。
- 局中状态不落盘：退到后台超过小程序回收阈值会从头开始。一局十分钟，暂不做断点续玩。
- `appid` 是 `touristappid`（游客态）。绑定真实小程序时，由发布流程替换，不要手改。

## 六、口径

与网页版一致，改动后一起核：146 道岔路（96 二选一 + 50 多选）/ 146 道开局题 /
30 个随机事件 / 14 组连锁 / 20 种结局。
